> 🧮 A sleek, interactive, and colorful command-line calculator built with **Node.js (ESM)**.  
> Perform math operations right from your terminal — with style and color!

---

## 🚀 Features
- 🎯 Interactive prompts using **Inquirer**
- 🌈 Vibrant colored output with **Chalk**
- 🧩 Modular architecture (`math.js` + `app.js`)
- ⚙️ Easy setup with **npm**
- 💻 Works on Windows, macOS, and Linux

---

##  Installation

**### Clone & Run Locally**
git clone https://github.com/nemo18/colorful-calculator.git
cd colorful-calculator
npm install
npm start

**### Tool and Purpose**
Node.js (ES Modules)	Runtime environment
Inquirer	Interactive CLI prompts
Chalk	Colorful terminal output
npm	Package management
Git + GitHub	Version control & hosting
